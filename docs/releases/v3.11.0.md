### v3.11.0（数据不丢 + 安全加固 + 启动提速）

**你的数据更难丢了**
- 数据文件损坏（被截断、被改成非法格式）时不再启动失败：程序会先把原文件另存一份
  `superstar-data.json.corrupt-<时间>` 再以干净状态启动，你可以手工找回内容
- 「清空记录」不再不可逆：清空前自动备份到 `data/history-backups/`，保留最近 5 份；
  备份写不下去时直接拒绝清空，不会出现"记录没了但也没留底"
- 签到历史字段被写坏时自动跳过坏记录，不再导致签到流程中途报错

**设置更容易存对**
- 轮询间隔、免打扰时段、重试次数等填错会明确告诉你哪个字段、允许什么范围，
  不再出现"提示保存成功但其实被丢掉了"
- 修复：日报/预检查时间选 0 点会被存成 22 点
- 修复：免打扰时段填非法时间会让窗口被悄悄算窄
- 保存设置等整页刷新后回到你原来的滚动位置，不再跳回顶部

**更安全**
- 钉钉 AppSecret 与账号密码一样用 Windows DPAPI 加密存储，不再明文写进配置文件
- 修复：在钉钉设置里留空 AppSecret 再保存，会把已配置的密钥抹掉
- 控制台全部响应加 CSP / X-Frame-Options 等安全头，恶意脚本无法外联或加载远程代码
- 依赖安全审计：3 个高危漏洞清零

**更快**
- 默认轮询模式不再加载 IM 相关的大型组件：后端启动实测 758ms → 260ms

**手机 / 触屏**
- 筛选按钮、日志级别按钮、开关的点击区域抬到 40px 以上（此前 22–26px 容易点不中）

**安装与更新**
- 用户数据（配置与签到记录）从程序目录迁到 `%APPDATA%\学习通自动签到\`：
  卸载不再残留你的数据，重装数据还在；旧数据首次启动自动搬运
- 修复：点「更新并重启」会弹安装向导、看起来像没反应 —— 现在静默安装并自动重启

**质量**
- 回归测试从 27 条增至 61 条，CI 在打包前强制执行：测试不过不出安装包

**下载说明**：`SuperstarCheckin-Setup.exe` 为固定最新链接；国内可走
`https://gh-proxy.com/` 前缀镜像。安装包约 106 MB（主体是 Electron 运行时）。
