## v3.6.0

### 功能调整
- 彻底移除手势签到与拍照签到：检测到这两类签到时仅推送提醒，请在手机学习通 APP 内手动完成（软件不再要求上传照片，`config.yaml` 的 `photo` 配置项一并移除）
- 手机上传页收敛为「二维码签到专用」，去掉拍照上传入口

### 问题修复
- 修复「签到前确认」取消后无法恢复：取消不再永久标记该签到，下一轮检测仍可重新触发
- 修复轮询监听器启动时首次扫描重复执行一次的问题
- 修复控制台「近 14 天签到趋势」统计取错字段导致图表恒为 0 的问题

### 界面重做
- 桌面端：顶部新增实时状态条（监听模式 / 登录状态 / IM 通道 / 二维码待签）；侧边栏增加呼吸式运行指示与账号数量；页面标题配副标题说明
- 移动端：主操作改为右下悬浮按钮（拇指可达区）、弹窗改为底部弹层（适配安全区）、底部标签栏增加选中指示与窄屏横向滑动兜底
- 配色与质感统一：暖白画布 + 单一暖橙强调色，多层阴影与按压反馈对齐 Material 3 / iOS HIG

### 工程
- 新增 `npm run validate:ui`：校验控制台页面 CSS 括号配平、脚本语法与关键元素完整性，避免手改样式后出现「页面能用但样式悄悄失效」
