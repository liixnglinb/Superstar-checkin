v3.11.1（2026-10-07）修的是「软件内更新」这条路。

**软件里点更新，以前一定会失败**

从 v3.8.0 开始，界面上点「更新并重启」都会停在「更新失败 / Please check update first」，
下载根本没开始。原因是那次改版把更新检查换成了自己实现的「多源测速选最快」，
但漏掉了下载器要求的前置一步——没查过就不许下。这 8 个版本里所有人都升级不了，
不是网络问题，也不是你配置的问题。现在补上了，并且换备用下载源时也会重新查一次。

**更新说明窗口不再显示排版符号**

以前说明里会出现 `###`、`**` 这类在网页上才有效果的记号，看着像乱码。
现在软件内显示的是纯文本，GitHub 上的 Release 页面照旧正常排版。

**这一次请手动装**

因为坏掉的正是升级通道本身：如果你现在装的是 v3.8.0 ~ v3.11.0 之间的任意版本，
软件内点更新仍然会失败（那个版本里的更新逻辑是旧的）。
请去下载页下载安装包覆盖安装一次，配置和签到记录都不会丢。
装上 v3.11.1 之后，以后的版本就能在软件里直接更新了。
