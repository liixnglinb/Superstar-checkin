> 一款面向学生的学习通（超星）自动签到桌面软件。安装后常驻系统托盘，自动监听课程签到活动，支持普通 / 位置 / 二维码三种签到，内置智能轮询、漏签预警、签到二次核对、多账号管理、课表可视化等丰富功能。

---

## ✨ 软件亮点

- **纯桌面软件**：Electron 自绘窗口 + 本地 Node 服务，不依赖浏览器，开箱即用
- **三种签到全覆盖**：普通签到全自动、位置签到自动定位、二维码签到拖图即签
- **智能防风控**：模拟人类延迟签到、白天/夜间智能轮询间隔、签到前确认可取消
- **多账号共用**：支持多个学习通账号同时监控，各自独立统计签到数据
- **数据可视化**：签到趋势图、签到日历、课表卡片、各账号独立统计
- **自动更新**：内置检查更新，GitHub Releases 一键下载安装（国内镜像加速）
- **隐私安全**：账号密码本地 DPAPI 加密存储，不上传任何服务器

## 📦 安装

### 方式一：下载安装包（推荐）

从 [GitHub Releases](https://github.com/liixnglinb/superstar-checkin/releases) 下载最新版 `学习通自动签到-安装版-*.exe`，双击安装即可。

- 安装到当前用户目录，无需管理员权限
- 安装完成自动启动，桌面和开始菜单自动创建快捷方式
- 支持 Windows 10 / 11（x64）

### 方式二：从源码构建

```bash
# 克隆仓库
git clone https://github.com/liixnglinb/superstar-checkin.git
cd superstar-checkin

# 安装依赖
npm install

# 编译 TypeScript
npm run build

# 打包 NSIS 安装程序
npx electron-builder --win nsis --x64
# 产物在 dist-electron/ 目录
```

## 🚀 快速上手

### 第一步：登录账号

1. 启动软件后，首次进入会弹出**免责声明**，阅读后点击「同意并继续」
2. 进入左侧导航栏的**「设置」**页
3. 在「账号配置」中填写你的学习通账号（手机号）和密码
4. 点击「保存账号」，软件自动登录并加载课程列表

> 支持多账号：点击「添加账号」可配置多个学习通账号，所有账号都会同时监控签到。账号密码使用 Windows DPAPI 加密存储在本地 `config.yaml` 中。

### 第二步：选择监听课程

1. 进入**「课表」**页，查看所有已加载的课程
2. 点击课程卡片可切换监听状态（绿色「监听中」表示正在监控）
3. 已结课的课程会自动标记「已结课」并停止监听

### 第三步：开始自动签到

配置完成后，软件会自动在后台运行：

- 检测到**普通签到** → 自动提交
- 检测到**位置签到** → 自动读取老师发布坐标，在 10 米范围内生成签到点并提交
- 检测到**二维码签到** → 推送提醒，把二维码图片拖入软件即可自动完成
- 检测到**拍照/手势签到** → 推送提醒（本软件不支持自动完成，请在学习通 APP 手动签到）

## 🎯 功能详解

### 三种签到类型

| 签到类型 | 自动化程度 | 说明 |
|---|---|---|
| **普通签到** | 全自动 | 检测到签到活动后自动提交，无需任何操作 |
| **位置签到** | 全自动 | 自动读取老师发布的坐标，以老师位置为中心 10 米半径内生成签到点，模拟真实位置提交 |
| **二维码签到** | 半自动 | 检测到后推送提醒，把任意签到二维码图片拖入软件窗口（或点击右上角「二维码签到」按钮上传），自动识别 enc 参数并完成签到。二维码更新后拖入新码即可 |

> **拍照签到、手势签到**：已从软件中移除。检测到这两类签到时会推送提醒，请在学习通 APP 中手动完成。

### 智能防风控功能

- **模拟人类延迟**：检测到签到后不立刻提交，随机等待 30~300 秒（可配置）再签到，避免"老师刚发布你就秒签"被怀疑
- **签到前确认**：检测到签到后先弹通知倒计时（默认 10 秒），可点击取消，超时自动签。适合"这门课今天想自己签"的场景
- **智能轮询**：白天（默认 8:00-22:00）用配置的短间隔轮询，夜间自动切换为 3 倍长间隔，减少无效请求和被风控概率
- **轮询抖动**：每次轮询叠加 0~抖动值的随机延迟，避免固定节奏被风控识别

### 签到保障功能

- **签到后二次核对**：提交成功后再次查询学习通平台确认已签到，避免"显示成功实际没签上"
- **失败自动重试**：签到失败自动重试（默认 3 次，间隔 5 秒），异常不影响后续签到
- **课前预检查**：每天指定时间（默认早上 7 点）自动检查所有账号 Cookie 有效性和学习通网络连通性，有问题立即推送提醒，避免人到教室才发现登不上
- **漏签预警**：每日签到日报中检查监听中的课程最近 3 天零签到，列出课程名单推送提醒
- **看门狗监控**：持续监控 IM 连接和签到活动，超过 15 分钟无活动自动告警

### 数据统计与可视化

- **签到趋势图**：近 14 天签到成功/失败趋势，一目了然
- **签到日历视图**：日历形式展示每天签到情况，绿色=成功，红色=失败
- **课表页**：课程卡片网格，每门课显示老师、监听状态、签到成功/失败数，点击切换监听
- **各账号独立统计**：总览页显示每个账号的成功数、失败数、成功率、最近签到时间
- **每日签到日报**：每天指定时间（默认 22:00）推送当天签到汇总
- **每周签到周报**：每周日推送本周签到统计

### 实用工具

- **课程备注**：给每门课加备注（如"老师爱点人""单周上课""周三在312"），课表页直接显示
- **位置快捷收藏**：常用位置（宿舍/教室/图书馆）一键保存切换，位置签到时快速选择
- **签到活动详情**：课表页点击「详情」查看某门课的所有签到记录（时间、类型、账号、结果）
- **配置导入/导出**：一键导出配置（JSON，密码自动脱敏），换电脑或给同学用时一键迁移
- **网络诊断**：一键检测公网/登录域/课程接口/签到接口/IM 通道，失败给出原因和建议
- **代理配置**：支持 HTTP 代理，网络受限环境下也能正常使用
- **日志导出**：一键导出完整运行日志，方便排查问题

### 通知推送

支持多种通知渠道，签到结果实时推送：

- **钉钉机器人**：Webhook 推送
- **Bark**：iOS 推送
- **PushPlus**：微信推送
- **邮件**：SMTP 邮件通知
- **桌面通知**：Windows 系统通知（默认开启）

### 软件体验

- **自绘标题栏**：深炭灰 + 珊瑚橙暖色主题，去掉系统大黑边，标题栏与内置 UI 融为一体
- **系统托盘**：关闭窗口最小化到托盘，后台继续运行；托盘菜单显示今日签到统计、最近签到记录
- **免打扰时段**：可配置免打扰时间段，该时段内不推送桌面通知
- **检查更新**：内置更新检测，GitHub Releases 一键下载安装（自动使用国内镜像加速）
- **免责声明**：首次启动弹出免责声明，明确使用风险

## ⚙️ 配置文件（config.yaml）

首次运行自动生成在软件安装目录。常用配置项：

```yaml
# 账号配置（密码 DPAPI 加密存储）
accounts:
  - username: 手机号
    password: 加密后的密码

# 监听配置
listener:
  mode: hybrid           # im = IM消息 | poll = 轮询 | hybrid = 两者
  pollInterval: 30000    # 轮询间隔（毫秒）
  pollJitter: 15000      # 轮询抖动（毫秒）

# 签到配置
checkin:
  delay: { min: 15, max: 45 }      # 签到随机延迟（秒）
  retry: { maxAttempts: 3, delayMs: 5000 }
  verify: { enabled: true }          # 签到后二次核对
  humanDelay: { enabled: false, minSeconds: 30, maxSeconds: 300 }  # 模拟人类延迟
  confirmBefore: { enabled: false, waitSeconds: 10 }  # 签到前确认

# 位置签到
geo:
  locationRadius: 10      # 位置签到半径（米）
  favorites: []            # 常用位置收藏

# 智能功能
preCheck: { enabled: true, hour: 7 }       # 课前预检查
smartPoll: { enabled: true, dayStart: 8, dayEnd: 22, nightMultiplier: 3 }  # 智能轮询
report: { enabled: true, hour: 22, weekly: true }  # 每日/每周报告

# 通知推送
notify:
  desktop: { enabled: true }
  quiet: { enabled: false, start: "23:00", end: "07:00" }
  channels:
    - type: dingtalk      # 钉钉机器人
      enabled: false
      config: { webhook: "", secret: "" }
    - type: bark          # Bark iOS 推送
      enabled: false
      config: { url: "", key: "" }
    - type: pushplus      # PushPlus 微信推送
      enabled: false
      config: { token: "" }
    - type: email         # SMTP 邮件
      enabled: false
      config: { smtpHost: "", smtpPort: 465, from: "", password: "", to: "" }

# 网络配置
proxy: ""                 # HTTP 代理（可选）
dingtalk: { port: 3456 }  # 本地服务端口
```

## 🛠️ 技术栈

- **前端**：原生 HTML/CSS/JavaScript（服务端渲染单模板，无框架依赖）
- **后端**：Node.js + TypeScript
- **桌面壳**：Electron（自绘标题栏 + 系统托盘）
- **打包**：electron-builder（NSIS 安装程序）
- **签到引擎**：学习通 IM 实时通道 + 轮询兜底（混合模式）
- **二维码识别**：jsQR（纯 JS 二维码解析）
- **通知推送**：钉钉 / Bark / PushPlus / SMTP 邮件 / Windows 桌面通知
- **数据存储**：YAML 配置文件 + JSON 历史记录（本地文件，无数据库）
- **密码加密**：Windows DPAPI（数据保护 API）
